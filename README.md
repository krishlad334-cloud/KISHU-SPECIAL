# Kishu's Birthday Surprise 💕

A special romantic and modern birthday website created for **Kishu** for her birthday on **2 July**.

Features soft pink and lavender aesthetic, interactive sealed wax letter, candle blowing cake, floating rose petals, music player, quotes, and wishes.

## Development

```sh
npm i
npm run dev
```

## Production Build

```sh
npm run build
```

Generates production-ready files in the `dist` folder.
